## 📌 Overview

**My Guest Book** is a lightweight, single-page web application that allows visitors to leave feedback, ratings, and site impressions. Styled with a modern aesthetic using the Inter font and a sleek color palette, it offers a smooth interactive experience for users navigating your personal portfolio or website.

---

## ✨ Features

* **🎨 Modern Minimalist UI:** Designed with clean card layouts, subtle shadows, and responsive form controls matching contemporary web standards.
* **📱 Fully Responsive:** Adaptive layout built to look great across mobile devices, tablets, and desktop monitors.
* **⚡ Serverless Integration:** Utilizes [FormSubmit](https://formsubmit.co/) to deliver guestbook entries directly to your inbox without requiring a backend server.
* **🚀 Redirect Easter Egg:** Configured to automatically redirect visitors to a fun custom page upon successful submission.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic forms, fieldsets, and options)
* **Styling:** Vanilla CSS3 (CSS Variables, Flexbox, transitions, and focus states)
* **Backend Integration:** FormSubmit API
